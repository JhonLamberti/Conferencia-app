# Conferência de Folha PDF x Ponto

Versão com exportação limpa de divergências.

## Como rodar
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Saída do Excel
- **Divergências**: aba principal, mostra apenas problemas encontrados.
- **Resumo**: indicadores gerais da conferência.
- **Completo**: comparação completa para auditoria.
- **Eventos PDF**: dados extraídos do PDF.
- **Totais Ponto**: dados extraídos da planilha.
